Clip 是什么？

Clip 是免费开源的 Mac 截图工具。连按两下 ⌘，框住一个区域或窗口，标注后复制、保存或贴图。也可以录成 MP4 或 GIF，或复制图中文字。Clip 从不上传任何内容，也不收集数据，只在你检查更新时联网。文字识别在本机由 Apple Vision 完成，Vision 失败时由内置模型接手。原生 AppKit 通用应用，需要 macOS 14 或更高版本。

安装

Clip 未经 Apple 公证。首次打开时允许一次即可。

获取应用

下载 Clip-0.5.0.dmg，打开后把 Clip 拖进「应用程序」。

先打开一次

双击 Clip。macOS 提示无法验证开发者时，点「完成」。再到「系统设置 › 隐私与安全性」点「仍要打开」。

允许两项权限

「辅助功能」用于连按 ⌘ 触发，「屏幕录制」用于截图。Clip 会通过系统弹窗申请。

需要 macOS 14 或更高版本。

从源码构建

需要 Xcode 26 或更高版本。一个脚本完成编译、签名、装到 /Applications 并启动。 

git clone https://github.com/chengffei/clip.git
cd clip
bash scripts/rebuild-and-open.sh

只装 Command Line Tools 无法编译权限面板用到的 SwiftUI 宏。

常见问题

关于安装和使用 Clip 的常见问题。

怎么用 Clip 截图？

连按两下 ⌘ 键。拖出一个区域或点一下窗口，想标注就标注。然后点对勾，或再连按两下 ⌘，复制到剪贴板。

Clip 会把截图上传到别处吗？

不会。Clip 不上传，不要账号，不收集数据。只在你点「检查更新」时联网。截图进剪贴板或你选的文件夹，文字识别在本机运行。

为什么 macOS 提示无法验证开发者？

Clip 已签名，但未经 Apple 公证。先打开一次并关掉提示，再到「系统设置 › 隐私与安全性」点「仍要打开」。只需做一次。

Clip 需要哪些权限？

「辅助功能」，用来识别连按两下 ⌘；「屏幕录制」，用来截取屏幕。Clip 会通过系统弹窗申请这两项。

Clip 和 Shottr、CleanShot X、PixPin 有什么不同？

Clip 免费、开源，只在检查更新时联网。Shottr 更小，但不能录屏。CleanShot X 功能更多，带云分享，售价 35 美元。PixPin 免费且功能更多，但闭源，安装包 127 MB。

免费。Clip 以 MIT 协议免费开源。
